# Cricket Analysis Using MySQL
## 📌 Project Overview

Cricket Analysis Using MySQL is a database project developed to store, manage, and analyze cricket-related data. The project mainly focuses on player and match performance statistics, helping to extract insights such as top batsmen, best bowlers, match outcomes, and overall team performance.

This project demonstrates the use of SQL concepts including database creation, table design, relationships, joins, aggregation, and data analysis.

## 🎯 Objectives

To build a structured MySQL database for cricket analytics.

To store player details, match details, batting and bowling statistics.

To analyze cricket performance data using SQL.

To extract insights such as run scorers, wicket takers, strike rates, team wins, etc.

## 📁 Database Structure

The project contains the following main tables:

Players Table

Stores details of players like name, age, country, and role.

Matches Table

Stores information of each match including date, teams, venue, and winner.

BattingStats Table

Contains batting records like runs scored, balls faced, fours, sixes, and strike rate.

BowlingStats Table

Stores bowling details like overs bowled, runs conceded, wickets taken, and economy.

## 🔍 Key Features

Organized cricket dataset stored in multiple relational tables.

Data can be analyzed based on batting & bowling performance.

Helps identify top performers across matches.

Supports team comparison and match result analysis.

Useful for beginners learning SQL & sports analytics.

## 📊 Insights That Can Be Derived

Total runs scored by each player.

Highest wicket takers.

Teams with most wins.

Best strike rate and economy performers.

Number of fours and sixes hit by each player.

Player performance comparison across matches.

## 🛠 Tools & Technologies

Database: MySQL

Query Editor: MySQL Workbench


## 📎 Outcome

The project successfully builds a cricket analytics system using MySQL, allowing performance evaluation using stored match and player statistics. This can be extended for dashboards, visualizations, or real-time sports analytics applications.
